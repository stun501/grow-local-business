How to print (A5)
-----------------
1. Open flyer-a5-arm-a.html or flyer-a5-arm-b.html in Chrome
   (or open flyer-a4-4up.html — it redirects to Arm A).
2. Ctrl+P → Save as PDF (or print directly).
3. Paper: custom 156 × 218 mm (trim + 4mm bleed) · Margins: None ·
   Background graphics: ON.
4. The file outputs 2 pages — page 1 front, page 2 back. Tell the printer
   this is double-sided A5 with 4mm bleed; they will trim to 148 × 210 mm.
5. Stock (from flyer spec): 400gsm uncoated, matte, no lamination.
