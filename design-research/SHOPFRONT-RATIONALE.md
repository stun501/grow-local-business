# Shopfront rationale (confirmation against brief)

**Direction used:** Shopfront (default) — not Enamel or Workshop.

| Decision | Choice | Why (vs generic SMB template) |
|---|---|---|
| Palette | Bottle `#12291F` · Bone `#F2EFE6` · Gold Leaf `#C6A15B` · Deep Brass `#A8813C` | British shopfront livery; deep green not kelly; gold sparingly; no pure white |
| Type | Fraunces + Archivo + Archivo Narrow | Display / body / utility pairing; no Inter/Poppins |
| Identity | Wordmark + gold underline rule; GL monogram | Retires ascending-arrow logo |
| Signature | Fascia band (hero + footer on hub; header + footer on flyer) | Shopfront abstracted — used exactly as briefed |
| Hero visual | CSS phone render of Instant Quote | Preference #1: product itself, not stock photography |
| Layout | Left-aligned throughout | No centre-then-left inconsistency |
| Surfaces | Flat fields, hairline gold rules | No gradients, no drop shadows |

**Revised away from previous build:** stock tradesperson photo, mint gradient washes, teal/lime CTAs, circular arrow buttons, centred hero, arrow icon logo, competing flyer headlines.
